# Dungeo: The Mind's Labyrinth

**Status:** PARKED pitch. Not the current game. Not implementation authority.

NCE Classic is the playable prototype. This document is an earlier story pitch about Adam daydreaming into a pixel labyrinth. It does not define rooms, checks, or the catalog.

## What it contributed

- Adam as a child prodigy and daydreamer, at a desk, building a world that can trap him.
- Sugar as a magical fuel in that imagined world.
- Memory shards, runes, and Echoes as fears given a body.
- A want for the game to feel like a psychological maze, not only a board.

## What it must not be built as

A 2D pixel RPG, a vast shifting labyrinth, puzzle biomes, cinematic scripts, or a second protagonist age. The frozen game is a 3×5 card board with a support hand.

## Dataset note

Echoes and sugar-lit rooms are tone references for the creature interview. They are not records, and they are not families. If a future creature should feel like a fear rather than a culinary joke, say that in `nce-classic-v01-decision-interview.md`. Do not import this pitch's plot as mechanics.
