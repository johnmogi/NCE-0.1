# Culinary dungeon MVP

**Status:** PARKED specification. Superseded by the NCE Classic prototype.

This file once described a solo culinary crawler: hero sheets, six stats, hunger, sweet tooth, dice, room smells, and a monster formula.

```text
Monster = size + food culture + creature type + weird trait
```

Examples sitting in the old spec: sticky sugar ant knight, haunted pickle troll, blueberry teapot gremlin, flaming falafel slime.

That loop is not the shipped loop. The shipped loop is one card check, repeated once, twice, or three times, plus a treasure choice that changes the hand.

## Explicitly not in prototype rules v0.1

- Classes and backgrounds
- Hunger and sweet tooth
- Dice
- Gold, mana, armor, recipes, and ingredients
- Traps as a room type
- Victory by collecting ingredients

## What may still inform the dataset

The formula and the examples are one candidate in the creature interview, beside Family / Transformation / Culinary Treatment / Quirk, and beside the 76 authored names.

A treasure in the old spec was a magical object. In the prototype, a treasure is a flavor name plus a keep-one card choice. Magical effects stay deferred even if a name from this list is later reused.

## Generator tables

The old class list, personality list, smell list, and trap list remain brainstorming. They are not tables the engine reads. If a table is approved later, it gets its own content file and its own checkpoint. It does not get hidden inside this parked spec.
