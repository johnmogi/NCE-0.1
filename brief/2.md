# Board and catalog decision log

**Status:** historical decisions that shipped. The long design chat this file used to contain is replaced by this log.  
**Authority for the current game:** `nce-classic-v01-checkpoint-1.md`.

## Decisions that became the generator

- The first product is NCE Classic, not Dungeo.
- The board is finite. A mutating or infinite dungeon is a later experiment.
- Every generation has at least one orthogonal path from Start to Royal. Rooms off that path are optional.
- Default size is 15 tiles, drawn as 3 columns by 5 rows.
- Start is the bottom center. Royal is the top center. The pictured journey reads upward.
- Smaller boards such as 3×3 were discussed for tutorials. They were not built. The shipped preset is 3×5 only.
- Room mix is fixed, not weighted: 4 Treasure, 4 Barrier, 5 Challenger, plus Start and Royal.
- Cleared rooms stay cleared and may be crossed. For the prototype, backtracking is allowed. One-way paths were not built.
- Walls were not part of the contract. The board is an open grid. That remains true on purpose.

## Decisions that became the catalog

The production set is 76 records, not a 52-card deck:

| Family | Count |
|---|---:|
| Ace heroes | 4 |
| Challengers, values 2–9, four elements | 32 |
| Royals, Jack Queen King, four elements | 12 |
| Champions, one per element, no gameplay | 4 |
| Barriers | 12 |
| Treasures | 12 |

Names can be discussed. During the freeze they are not to be rewritten in place to match a new creature grammar.

Tens were removed in the origin myth. The catalog still stores royal values 10, 11, and 12. Gameplay does not use those numbers as the Royal target. That difference is contained in `encounterTarget()`.

## Decisions that became prototype rules v0.1

The chat did not yet contain the final check grammar. The built grammar, accepted in the commit `44` review, is:

- Hero power 1, health 3, hand 4, maximum 6.
- A separate 32-card support deck.
- One check, with advantage +2, neutral 0, disadvantage −2.
- Barrier one success, Challenger two, Royal three.
- Treasure keeps one of two drawn cards and has no magic effect.

Element identities once sketched as speed, attack, healing, and defense were not implemented as hero roles. The cycle is the only elemental rule.

## Left as experiments

- A room that changes after you leave it.
- Admin-controlled percentage weights.
- A second and third element on the same hero.
- Suit art as the public face of the elements.
- Any Dungeo or Sugarbound ruleset.
